
# StudentHub – API Based Student Directory

## ONLEI Technologies – Web Development Internship
### Day 10: Fetch API, JSON & Asynchronous JavaScript

StudentHub is a responsive API-based web application developed using HTML, CSS, and JavaScript. It fetches sample user and post data from JSONPlaceholder and displays it dynamically.

## Features

- Fetch student-like user records using Fetch API.
- Display student name, email, and city.
- Fetch and display the latest posts.
- Search students by name, email, or city.
- Search posts by title.
- Loading indicators and error handling.
- Responsive dashboard design.
- Empty search result messages.
- JSON parsing and stringification.
- Promise and async/await demonstrations.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
- Async/Await
- JSONPlaceholder API

## API Endpoints

**Users API**
https://jsonplaceholder.typicode.com/users

**Posts API**
https://jsonplaceholder.typicode.com/posts

Note: JSONPlaceholder provides demonstration data, not real student records.

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Open index.html using Live Server.
5. Click Load Students or Load Posts.
6. Use the search fields to filter records.

## Concepts Learned

### 1. Fetch API
Used to retrieve data from external APIs.

### 2. JSON
Used JSON.stringify() and JSON.parse() to convert between JavaScript objects and JSON strings.

### 3. Promises
Used promises to handle asynchronous operations.

### 4. Async/Await
Used async and await to write readable asynchronous JavaScript.

### 5. Error Handling
Used try/catch and response.ok to handle API errors.
